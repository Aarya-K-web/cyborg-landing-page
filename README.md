# Cyborg Landing Page — NEXUS

A responsive landing page built on a cyborg/sci-fi theme with modern UI/UX.

## Features
- Custom animated cursor
- Glitch text effects & scanline overlay
- SVG cyborg portrait with live animations
- Scroll-triggered stat counters
- Fully responsive (mobile hamburger nav)
- Sections: Hero, Stats, Features, Specs, Timeline, CTA

## Tech Stack
HTML5 · CSS3 · Vanilla JavaScript · Google Fonts
